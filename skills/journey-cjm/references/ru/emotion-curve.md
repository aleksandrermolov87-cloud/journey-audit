# Кривая эмоций

## Правило единицы времени

Один шаг — один цикл: пользователь делает одно действие → продукт или мир отвечает → пользователь что-то чувствует, и кривая сдвигается от прошлого уровня. Шаги не перекрываются, поэтому карта полна и без пересечений. Эмоция накопительная: провал сразу после подъёма бьёт сильнее, чем такой же провал в начале.

Шкала −2…+2 (половинки допустимы): +2 восторг · +1 доволен, надеется · 0 нейтрально · −1 раздражён, тревожится · −2 зол, готов бросить. Большинство путей начинаются чуть выше нуля: человек пришёл с намерением.

## Проверки

| Код | Проверка |
|---|---|
| EC1 | У каждой точки есть событие-причина в этом же шаге (не «в целом тревожно») |
| EC2 | Кривая хотя бы раз опускается ниже нуля. Если нет, это счастливая монотонность, типичная для ИИ: ищи, где спрятан провал |
| EC3 | Провал после пика объяснён: что именно обмануло ожидание |
| EC4 | Финал согласован с исходом: успех выше нуля, уход ниже |
| EC5 | Офлайн-шаги (найти документ, дождаться SMS, позвонить) есть на кривой. Самые глубокие провалы часто там |
| EC6 | Эмоции поставлены для этой персоны в этом контексте, а не «для среднего пользователя» |

## Типы причин провала

Каждому провалу ниже нуля присвой тип. От типа зависит, кто чинит:

| Тип | Кто чинит | Пример |
|---|---|---|
| Производительность | Инженеры | Долгая загрузка, таймаут |
| Продукт / UX | Продукт и дизайн | Функцию не найти, запутанный порядок, лишние поля |
| Ценность | Бизнес | Сервис не решает задачу: нет данных, нет услуги, нет права. Кнопкой не лечится |
| Внешняя зависимость | Партнёр, интеграция | Платёжный шлюз, госуслуги, OCR, LLM |
| Качество ответа ИИ | Промпт, данные, eval | Не тот язык или формат, общие слова, выдумка, недоверие, пользователь не знает, что спросить |

Провал ценности записывай отдельной находкой с `root_cause: "value-failure"`: вердикт поставит такую цель бизнесу, а не дизайну.

## Пики

Для каждого пика выше +1 назови причину: задача решена, быстрая или неожиданно удобная деталь, ответ ощущается личным. Пики — то, что TO BE не должен сломать. Перечисли их в `report.md` → «Что сохранить».

## Артефакт

`emotion-curve.svg` (скрипт `curve`) + таблица: шаг · эмоция · причина · тип провала. Если эмоции поставил ты, а не источник, отметь это (`assumption`).
