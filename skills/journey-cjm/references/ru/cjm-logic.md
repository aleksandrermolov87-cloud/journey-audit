# Логика CJM: проверки L01–L20

Тяжесть: **К** — путь не выполняет задачу или вводит в заблуждение; **В** — заметный провал опыта; **С** — пробел, который всплывёт позже; **Н** — качество карты.

Колонка «Скрипт»: ✓ — `journey_check.py check` находит сам, ◐ — находит кандидатов, решаешь ты, — — только чтение.

## Рамка

| ID | Проверка | Тяжесть | Скрипт |
|---|---|---|---|
| L01 | Есть триггер: что именно запускает путь | С | ✓ |
| L02 | Есть критерий успеха, сформулированный от пользователя и проверяемый | В | ✓ |
| L03 | Одна персона и один сценарий на карту. Две персоны в одной таблице — две карты | С | ✓ |
| L04 | Одно действие на шаг. Склеенные действия прячут ожидание и ошибки между ними | С | ◐ |
| L05 | У каждого сбоя есть выход (повтор, другой путь, человек). К — на моменте истины, В — в остальных шагах, С — выход не описан во входе (`recovery: "unknown"`) | К / В / С | ✓ |
| L06 | У каждого действия пользователя есть видимый отклик | В | ✓ |
| L07 | Путь заканчивается выполненной задачей или явным уходом. Обрыв на «видит ответ» без проверки, что ответ решил задачу, — пробел | С | — |

## Эмоции и доказательства

| ID | Проверка | Тяжесть | Скрипт |
|---|---|---|---|
| L08 | У каждой эмоции есть причина в событиях шага | С | ✓ |
| L09 | Скачок эмоции больше чем на 2 между соседними шагами объяснён событием (сбой, результат) | С | ✓ |
| L10 | Моменты истины подтверждены источником, а не догадкой | В | ✓ |
| L11 | Доля шагов с `assumption: true` указана. Больше 70 % — карта гипотетическая целиком, так и пиши | Н | ✓ |
| L12 | Финал согласован с кривой: «успех» при последней эмоции ниже нуля — противоречие | В | ✓ |

## Система и окружение

| ID | Проверка | Тяжесть | Скрипт |
|---|---|---|---|
| L13 | Шаги внешних систем (оплата, SMS, госуслуги, OCR, LLM) имеют описанный сбой | В | ✓ |
| L14 | Ожидание от 1 секунды сопровождается статусом; от 10 секунд — ещё и возможностью отмены или ухода с возвратом. Неизвестная длительность (`wait_s: "unknown"`) — С: пользователь не знает, сколько ждать | В / С | ✓ |
| L15 | Офлайн-шаги и шаги вне продукта (найти документ, позвонить, дождаться кода) есть в карте. Часто именно там самые глубокие провалы | С | — |
| L16 | Ни один шаг не опирается на экран, состояние или данные, которых нет во входных материалах. Сюда же — расхождение карты с работающим интерфейсом (снимки, прогон, код): карта описывает не тот продукт | К / В | — |

| ID | Проверка | Тяжесть | Скрипт |
|---|---|---|---|
| L17 | Каждый пункт видения владельца закрыт шагом или явно отмечен как не закрытый | В | ✓ (`vision`) |
| L18 | Нет шагов и обещаний, которых владелец не просил (лишняя функция, другой тон, расширение границ) | С | — |
| L19 | Термины в том, что видит пользователь (отклики любых шагов и тексты сбоев), — слова пользователя, а не внутренние названия сущностей и кодов. Кириллические внутренние слова добавь в `internal_terms` | С | ◐ |
| L20 | Количество шагов 6–20. Меньше — склеено; больше — смешаны два пути | Н | ✓ |

## Типичные ошибки путей, сгенерированных ИИ

Ищи их целенаправленно, они встречаются почти всегда:

- **Счастливая монотонность**: эмоция растёт или держится на каждом шаге, провалов нет.
- **Система всегда отвечает**: нет таймаутов, частичных результатов, отказов внешних сервисов.
- **Пользователь всегда понимает**: нет шагов «перечитывает», «ищет», «возвращается назад».
- **Внутренний язык**: в колонке «что видит» стоят названия статусов, сущностей и контрактов.
- **Отмена как ответ на всё**: у каждого шага есть «Отменить», но нет ответа на вопрос, что пользователь делает после отмены.
- **Нет возврата**: путь описывает только первый визит; повторный визит, восстановление сессии и история не описаны.
- **Граница без альтернативы**: «вопрос отклонён» без указания, куда пользователю идти дальше.
- **Сначала решение**: в колонке «боль» уже записаны фичи, а сама проблема пропущена.

## Как писать находку логики

`L05 · К · s5 «Проверка»` — Сбой «Проверка заняла > 60 с» не описан; выхода нет. Класс: нет во входе. Следствие: пользователь не знает, ждать или уйти. Исправление: статус с оценкой времени, кнопка «Сообщить, когда будет готово».
