# Семейство: логика CJM

> Русская версия `SKILL.md`. Справочники — `references/ru/`.

Вопрос семейства: **выполняет ли путь задачу пользователя так, как описано, и не противоречит ли сам себе.** Покрытие краевых случаев и нагрузка — работа других семейств; если заметил, запиши одной строкой в отчёт → «Передать другим семействам».

## Вход

`journey.json`, `frame.md` (рамка, видение, список доказательств), исходник. Без оркестратора сначала нормализуй путь по `journey-audit/references/ru/journey-format.md`.

## Методы

| # | Метод | Файл | Что даёт |
|---|---|---|---|
| 1 | Структурные проверки L01–L20 | `references/ru/cjm-logic.md` | Пропуски рамки, сбои без выхода, отклики, доказательства |
| 2 | Кривая эмоций | `references/ru/emotion-curve.md` | Эмоции следуют из событий; типы провалов; провал ценности отдельно от интерфейса |
| 3 | Слои сервиса | `references/ru/service-layers.md` | Что видит пользователь, что делает система, что за ней; где карта путает слои |
| 4 | Ревью зрелой карты | `references/ru/health-review.md` | Противоречия между разделами, расхождение с продуктом, моменты истины, перекос |
| 5 | Сверка с видением | `references/ru/vision-diff.md` | Закрыто / под риском / нарушено / не упомянуто + что ИИ добавил без запроса |

Порядок: механика методов 1–3 скриптом → ручная часть, начиная с метода 4 → ручная часть методов 1–3 → метод 5.

```bash
python3 <Script> check  <work>/journey.json --json > <work>/cjm/script-check.json
python3 <Script> vision <work>/journey.json --lang ru
python3 <Script> curve  <work>/journey.json --lang ru -o <work>/cjm/emotion-curve.svg
```

`<Script>` — `journey-audit/scripts/journey_check.py`, путь передаёт оркестратор.

Тяжесть из скрипта стартовая: пересмотри её по смыслу и напиши в находке, если меняешь.

**Самое ценное скрипт не видит**: цель, которую отменяет этап; карта, описывающая не тот продукт, что работает; скрытая смена режима; обещания, которые путь не выполняет. С них начинай ручную часть (метод 4).

## Выход

- `<work>/cjm/findings.json` — по контракту `journey-audit/references/ru/findings-contract.md`, id `CJM-NN`, отчёт — в поле `report_md`.
- `<work>/cjm/emotion-curve.svg`, `<work>/cjm/script-check.json`.

## Границы

Не меняй `journey.json`. Ошибка нормализации — находка `low` с `check: "NORM"`. Готовых решений не проектируй — это работа вердикта: `fix_hint` — направление в одну-две строки.
