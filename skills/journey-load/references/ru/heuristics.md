# Эвристики по шагам

Индекс говорит, где тяжело, а эвристика объясняет почему и подсказывает, что менять. Проходи эвристики только по шагам с индексом ≥ 50 и по точкам ухода, иначе отчёт утонет.

## Нильсен (H1–H10), привязка к признакам нагрузки

| Код | Эвристика | Чаще всего видна в признаке | Вопрос к шагу |
|---|---|---|---|
| H1 | Видимость состояния системы | `wait_s`, `uncertainty` | Пользователь знает, что происходит и сколько ждать? |
| H2 | Язык пользователя | `new_terms` | Слова его, а не продукта? |
| H3 | Контроль и свобода | `uncertainty` | Есть выход и отмена без потери сделанного? |
| H4 | Единообразие | `new_terms`, `decisions` | Одно слово — одно значение, одна кнопка — одно действие во всём пути? |
| H5 | Предотвращение ошибок | `fields`, `decisions` | Ограничения ввода, значения по умолчанию, предупреждения до ошибки? |
| H6 | Узнавание вместо припоминания | `memory_items` | Нужное с прошлых шагов показано, а не держится в голове? |
| H7 | Гибкость | `decisions`, KLM | Есть короткий путь для вернувшегося? |
| H8 | Минимализм | `decisions`, `max_options` | Каждый элемент нужен на этом шаге? Одна главная кнопка? |
| H9 | Распознать ошибку и выйти из неё | `uncertainty` | Ошибка говорит, что случилось, почему и что делать? |
| H10 | Помощь | `new_terms` | Подсказка там, где термин, а не в отдельном разделе? |

## Круг

| Код | Принцип | Вопрос |
|---|---|---|
| K1 | Не заставляй думать | Есть ли на шаге хоть один вопросительный знак в голове: «это кнопка?», «что значит это слово?» |
| K2 | Клики не важны, важна уверенность | Каждый клик очевиден и подтверждает, что пользователь на верном пути? Три очевидных клика лучше одного раздумья |
| K3 | Убери половину слов | Приветствия, инструкции, которые никто не читает, вежливый шум |
| K4 | Тест багажника | Попав на шаг по ссылке, понятно: что за сервис, где я, что можно сделать, где главное действие? |

## Быстрые проверки

- **Прищур**: что видно первым? Это то, что нужно сделать?
- **Три секунды**: новичок понял бы, что делать?
- **Вычитание**: убери элемент — что-то важное сломалось? Если нет, он лишний.
- **Телефонный звонок**: можно пересказать экран по телефону без путаницы?
- **Память**: несёт ли пользователь что-то в голове на следующий шаг?

## Тексты

Короткие фразы, действительный залог, слова пользователя, главное в начале фразы, без отрицаний там, где можно сказать прямо. Длина ответа на телефоне: если главное не помещается в первый экран, это `memory_items` + `context_switches` (прокрутка туда и обратно).

## Запись находки

`LOAD-07 · C-s7 · high` — «Ввод адреса на телефоне: 40 символов, 2 поля, 1 переключение контекста; индекс 54 (low/low), H5, H6, K2». `fix_hint`: «предложить адрес регистрации по умолчанию; ввод только для нового адреса».
